# Waste to Energy website

This is a static, responsive website. It needs no build step or server-side code.

## Publish with GitHub Pages

1. Push this folder to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, then select `main` and the `/(root)` folder.
4. Save. GitHub will provide the public HTTPS link.

The video used by the page is `media/project-footage-web.mp4`: a 480p H.264/AAC MP4 with web streaming metadata. It is 17.5 MB, so it can also be uploaded through GitHub's browser interface and loads efficiently on phones.

`media/IMG_8001.MOV` is the original 550 MB source file and is intentionally excluded from Git. Keep it locally as your editable master copy.
